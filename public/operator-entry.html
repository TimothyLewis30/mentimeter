Admin Room

Buka kontrol room

Halaman Admin Room adalah satu-satunya tempat untuk memulai room, merekam layar, dan mengakhiri sesi. Tempel link operator + token yang diberikan Superadmin.

Belum punya link operator?

Hubungi Superadmin untuk meminta link Operator. Link itu berisi token rahasia yang hanya boleh dipegang perangkat operator room.
